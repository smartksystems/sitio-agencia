# SMART K SYSTEMS – sitio-agencia
Astro 5 + Tailwind CSS 4. Sitio estático, sin JS de framework.

    npm install
    npm run dev      # desarrollo
    npm run build    # genera /dist

Colores y tipografías: `src/styles/global.css` (bloque @theme).
Textos: `src/pages/index.astro`. SEO global: `src/layouts/Layout.astro`.
Vercel detecta Astro automáticamente.
